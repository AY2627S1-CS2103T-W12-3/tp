CoordiMate

Your CCA committee's contacts, events, and attendance, in one place.

CoordiMate is a desktop app for university CCA EXCO members. Keep everyone your committee works with, plan events and their members, and take attendance, all by typing short commands. A visual interface shows the results as you work, and everything is saved on your own computer.

Download the latest release · Get started · See all commands

Why CoordiMate?

Everyone your committee works with
Save members, sponsors, and university staff with their roles, organisations, birthdays, and notes. Group them with tags, find them with search and filter, and see at a glance who is on leave.

Events, members, and attendance
Create events, assign members, and mark each member present or absent. The Events tab shows who has and hasn't been marked, and reminders appear the day before an event starts.

Built for handovers
Archive past events and former contacts instead of deleting them, so the next committee keeps the history. Data is stored in a single, human-readable file that you can back up or pass on.

Fast for people who type
Every action is a short command, and you can move through cards, switch views, and recall earlier commands without touching the mouse. New users can follow the built-in tutorial, which opens on the first launch.

Get started

  1. Make sure Java 25 or later is installed on your computer.
  2. Download the latest .jar file from the releases page.
  3. Run it from a terminal with java -jar followed by the file name, and follow the tutorial.

The User Guide explains every command, and its Quick start section has step-by-step setup instructions.

For developers

Interested in how CoordiMate works, or in contributing? The Developer Guide describes its design and implementation, and the source code is on GitHub. Meet the team on the About Us page.
