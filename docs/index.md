# CoordiMate

[![CI Status](https://github.com/AY2627S1-CS2103T-W12-3/tp/workflows/Java%20CI/badge.svg)](https://github.com/AY2627S1-CS2103T-W12-3/tp/actions)
[![codecov](https://codecov.io/gh/AY2627S1-CS2103T-W12-3/tp/branch/master/graph/badge.svg)](https://codecov.io/gh/AY2627S1-CS2103T-W12-3/tp)

![Ui](images/Ui.png)

**CoordiMate is a desktop application that helps university CCA EXCO members organise committee information and coordinate their work.** It supports contact and tag management through a CLI (Command Line Interface) and GUI.

* If you are interested in using CoordiMate, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing CoordiMate, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
